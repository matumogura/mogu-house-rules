01
BEFORE THE GAME — CHARACTER 6版 P40

卓前：新規PC作成

STEP 1

ステータス振り

6版 P45

キャラ作成 と入力して一括でステータスを振ってください。

RULE振り直しは無制限。入れ替えは同ダイス内なら自由（3d6⇔3d6、2d6+6⇔2d6+6）。HOでステータス指定がある場合は入れ替え後に上書きできます。
STEP 2

技能値の上限

  • 技能値上限は 85
  • 職業技能 1つだけ90可
  • 回避のみ上限 75

特徴表 / シナリオによって変化の可能性あり。

公式メモ公式（6版）に固定の技能上限はなく、成長で90を超えることも可能。本卓は独自に上限を設定しています。
STEP 3

特徴表

2015

特徴表 と入力し、特徴表2つの組み合わせを 最大4セット 振って1セット選択。

HO制などで特徴表がHOにそぐわない場合は追加振り直しも許可。効果は同卓者全員が使用している場合に適応。使用時はCSに記入。

MISC

細かいルール

  • 英語の初期値は EDU*3
  • SAN10を捧げてPOW1と交換できる（POW+1毎に最大SAN-10）6版 P113
90

職業技能90 / 初期値90

6版 P61

初期値を90で取った探索者は、成長時に 2d6のSAN回復 を行って良い。

発狂

SAN

正気度のあつかい

  • セッション中は例えSAN値が0になっても NPC化しない。良い治療を受けると1ヶ月につき 1d3回復。
  • 0になってから追加チェックが発生した場合、治療不可・ロストとする。
  • 継続探索者は、時間経過の療養としてシナリオ開始時に SANを1d3回復 できる。
  • 自主SANC：任意のタイミング・値で行える。原因が解決 or 生還後に、振った値と同値での振り直しと回復を行える。
公式メモ公式では通常、SAN0で永久的狂気・実質ロスト。本卓はセッション中のNPC化なし＋条件付き回復に緩和しています。

回復

治療 — 応急手当 / 医学

6版 P64

精神分析

発狂の抑制・解除

6版 P90

成功で一時的 / 不定 の発生をシナリオ終了時まで一時的に抑えられる。一時的・不定問わず発狂を解除できた時は SAN値を1d3回復 可能。

精神分析

こぶし版

こぶし技能の成功で、ダメージなしの一時的狂気の解除が可能。失敗の場合はダメージが入るが正気には戻る。

07
COMBAT

戦闘

BASICS

行動順とラウンド

6版 P65

ラウンド（R）制、DEX順で行動。DEX同値は1d100を振り、出目の低い方が先。素早いPCのディレイは自由。

1Rに行える行動は 自発行動（技能を振る・長めの話をする等）と 防御判定（回避・庇う・受け流し）を 1回ずつ。

DEFENSE

各種防御アクション

  • 反撃状態 — 回避しない宣言をしていると、相手の攻撃失敗時にカウンター可能。基本的に神話生物には反撃状態を適応。7版 P105
  • 受け流し — 組み付き2回 / 武道 / MA で可能。近接武器にのみ可能（遠距離武器不可）。6版 P66
  • 庇う — DEX*5で判定。成功で全て肩代わり、失敗で二人共半分ずつ負う。
攻撃

攻撃時 C / F

C：必中 / ダメージ二倍 から選択（1クリは両方適応）。

F：次回攻撃回避不可 / 被ダメージ二倍 / 次R自発行動不能 から選択。

防御

防御時 C / F

C：カウンター可能。好きな攻撃技能を振れる。

F：被ダメージ二倍 / 次R自発行動不能 から選択。

補佐

戦闘補佐

目星成功で 攻撃技能+30% か 相手の回避-30%。他人へバフ譲渡可（重ねがけ不可）。

09
7TH EDITION

7版について

OVERVIEW

受け入れと変更点

7版のCSも受け入れます（6版・7版の両方のルールを採用する場合あり）。［CON*3目標 → CONハード成功目標］ 等の変更が入ることがあります。

技能・戦闘・成長の各ルールは基本的に6版と共通で、判定書式のみ7版準拠。狂気は下記の発作コマンド（BMR / BMS）を使用します。

判定

難易度と書式

CC(x)<=（目標値）(難易度)　x：ボーナス・ペナルティダイス

  • r — レギュラー（書かなくてもいい）
  • h — ハード（1/2）
  • e — イクストリーム（1/5）
  • c — クリティカル（1Cのみ）
例）CC<=70r　CC1<=60h　CC-2<=50e　CC2<=99c
PUSH

プッシュロール（ゴネ）

7版 P80

技能失敗時、悪あがきで追加の技能を振る提案ができる。内容によっては最初と異なる技能でも良い。2連続失敗で 面白い不都合 が起こる。

KPは振る前に何が起こるか予告するので、酷い提案なら取りやめてもOK。

LUCK

幸運の消費

7版 P95,121,150

幸運を消費して出目を下げられる。幸運1につき出目1。1話終わるごとに 1d10+10 回復（回復上限は最初の幸運+10）。

MADNESS

7版 P151
  • BMR — 狂気の発作（リアルタイム）
  • BMS — 狂気の発作（サマリー）
  • PH — 恐怖症（Sample Phobias）表 / MA — マニア（Sample Manias）表
  • FCL — 呪文の失敗 / FCM — 強力な呪文の失敗

7版で回すときの狂気はこのコマンドを使用します。
